# Common Robot Distractor Meshes

Optional generic robot subsystem meshes (intake, arm, chassis, etc.) as
`.obj`/`.stp`/`.step` files, used to occlude game pieces in renders for more
realistic training data (real Limelight footage often has robot parts
partially blocking the view of game pieces).

Not season-specific - reuse the same generic shapes every year. If this
folder is empty, distractors are simply skipped.
